# IoTPass Lite

개인 사용을 위한 비공식 Android 클라이언트입니다. 대상 서비스 제공사와 무관하며 제공사의 승인을 받지 않았습니다.

- 제공사의 앱 코드, 리소스, 이미지, 상표는 포함하지 않습니다. 'IoTPass'는 대상 서비스를 가리키는 명칭으로만 씁니다.
- 기존 서비스 계정과 정식 앱이 필요합니다. 가입·결제를 대신하지 않습니다.
- 대상 서비스가 변경되면 예고 없이 동작하지 않을 수 있습니다.

## 기능

- **도어 스캔**: 등록한 도어 리더의 BLE 광고를 시스템 PendingIntent 스캔으로 감지합니다. 포그라운드 서비스 없이 프로세스 종료 후에도 유지됩니다.
- **BLE 열기**: 감지된 리더에 요청을 보냅니다.
- **서버 열기**: 로그인 후 도어 목록을 조회하고 원격으로 문을 엽니다. 요청 간격은 5초로 제한됩니다.
- **이벤트 기록**: 스캔, 전송, 서버 요청 결과를 기기 안에 저장하고 앱에서 확인합니다.
- **오버레이/알림**: 전송 결과를 화면 오버레이 또는 알림으로 보여줍니다.
- **재등록**: 부팅, 패키지 교체, 블루투스 상태 변경 시 스캔을 다시 등록합니다.

## 요구 사항

- Android 12 이상
- JDK 17

## 빌드

```
./gradlew assembleDebug
./gradlew assembleRelease
```

릴리즈 서명에는 로컬 `signing.properties`와 키스토어가 필요합니다. 서명 키는 백업해 두세요.
