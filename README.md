# IoTPass Lite

연구/개인 기록 목적으로 만든 비공식 대체 클라이언트입니다. 정식 앱의 BLE 액세스 신호를
리버스 엔지니어링해 재구현했습니다.

## ⚠️ 안내

정식 서비스에 이미 가입·구매해 자신의 도어 리더를 쓰는 사람이, UX가 마음에 안 들어 만든
개인용 대체 클라이언트입니다. 가입·구매 절차를 대신하지 않고, 정식 앱도 계속 필요합니다.
리버스 엔지니어링한 프로토콜 기반이라 정식 서비스가 업데이트되면 예고 없이 깨질 수 있습니다.
연구/기록 목적의 공개입니다.

## 동작 원리

1. **스캔**: `DoorScanner`가 BLE 광고 패킷을 스캔해, 사용자가 등록한 도어 리더의
   advertisement를 식별합니다 (`DoorScanReceiver`).
2. **프로토콜 구성**: `DoorProtocol`이 정식 앱과 동일한 포맷으로 액세스 payload를
   구성합니다. 이 payload는 사용자가 정식 앱에서 이미 등록한 전화번호(자격 증명)를
   그대로 사용합니다 — 이 앱이 새 자격 증명을 발급하거나 우회 생성하지 않습니다.
3. **전송**: 구성된 payload를 BLE로 리더에 전달해, 정식 앱과 동일한 방식으로 접근
   요청을 보냅니다.
4. **재무장(Re-arm)**: 부팅, 패키지 업데이트, 블루투스 상태 변경 시 `RearmReceiver`가
   백그라운드 watcher를 다시 등록합니다.
5. **기록**: `EventLog`가 스캔/전송 이벤트를 로컬에 남기고, `EventLogActivity`에서
   확인할 수 있습니다.
6. **알림/오버레이**: `Notifications`, `SendOverlay`가 전송 결과를 사용자에게
   보여줍니다(오버레이 권한이 없으면 토스트로 대체).

루트 권한을 요구하는 기능은 의도적으로 제거했습니다.

## 빌드

```
./gradlew assembleDebug
```

Java(Kotlin 아님), 단일 모듈(`:app`), `androidx.core` 외 의존성 없음. minSdk 31.

## 포함하지 않는 것

- 정식 앱 APK, 디컴파일 산출물 — 저장소에 포함하지 않습니다.
- 오버레이 애니메이션 수동 테스트 버튼은 디버그 빌드에서만 노출됩니다
  (`BuildConfig.DEBUG`로 게이팅, 릴리즈 빌드에는 없음).
